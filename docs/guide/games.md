# ゲーム

[目次](../README.md) · [ポイント](points.md)

チェス・マインスイーパーは現在ローカル検証中です。以下は開発版での操作を含みます。

## 対戦を始める

| 入力例 | 遊び方 |
| --- | --- |
| `othello` | オセロ。6×6・8×8・10×10の盤面を選択 |
| `connectfour` / `cf` | 四目並べ。縦・横・斜めに4個並べる |
| `chess` / `チェス` | チェス。相手を募集、またはBotと対戦 |
| `minesweeper` / `マインスイーパー` | ひとり用。地雷を避けて安全なマスを開く |
| `janken` | じゃんけん。相手に見えない状態で手を選ぶ |
| `highlow 100` | 100ptずつ賭け、次のカードの大小を予想 |

相手を省略すると参加者を募集します。`othello @相手` のように指定すると、指名した相手だけが参加できます。ハイローは `highlow 100 @相手` の順です。
オセロ・四目並べ・チェス・じゃんけんは、募集者が **「Botと対戦」** を選べます。ハイローは人同士の対戦です。

## オセロ

`othello` で募集カードを開き、募集者が6×6・8×8・10×10の盤面を選びます。「承認する」で参加し、「Botと対戦」でひとりでも遊べます。

相手の石を挟める場所に置き、挟んだ石を自分の色に変えます。盤面の数字・英字と同じボタンを押してください。候補が多い場合はページを切り替えて選びます。置けない手番は自動でパスし、両者とも置けなくなると終了します。最後に石の多い側が勝ちです。1手の期限は3分です。

## 四目並べ

`connectfour` または `cf` で募集します。列のボタンを押すと、その列の空いている一番下に石が落ちます。7列×6段の盤面で、縦・横・斜めのどれかに先に4個並べた側が勝ちです。

満杯の列は選べません。盤面が埋まっても勝者がいなければ引き分けです。Bot戦にも対応し、1手の期限は3分です。

## じゃんけん

`janken` で相手を募集します。参加後にグー・チョキ・パーのボタンで手を選びます。選んだ手は両者が決めるまで相手に表示されず、揃ったところで勝敗が出ます。同じ手なら引き分けです。Bot戦にも対応し、選択期限は60秒です。

## ハイロー

`highlow 100` なら両者が100ptずつ賭けます。最初のカードを見て、次が大きいか小さいかをボタンで選んでください。相手の選択は結果が出るまで非公開です。選択期限は60秒で、Bot戦はありません。

片方だけ正解すると賭け金の合計を受け取り、両者正解なら返金、両者不正解なら没収です。確定する前にカードの賭け金を確認してください。

## チェス

`chess` で自由募集、`chess @相手` で指名対戦を始めます。Bot戦は募集者がボタンで選ぶか、このBotを相手に指定します。人間を指名した募集はBot戦に切り替えられません。

1. 座標ボタンで動かす駒を選ぶ。
2. 表示された合法手から移動先を選ぶ。
3. ポーンが昇格するときは、昇格先の駒を選ぶ。

| マスの色 | 意味 |
| --- | --- |
| 青 | 選択中の駒 |
| 緑 | 移動先 |
| 赤 | 駒取り・チェック |

白・薄いグレーの盤面に、白黒の駒を絵文字で表示します。動かせる駒数と合法手数もカードで確認できます。
キャスリング・アンパッサン・4種類の昇格・チェックメイト・引き分け判定に対応しています。

1手3分です。駒の選択や引き分け提案では期限は延びません。人同士の引き分けは相手の同意が必要で、Bot戦の引き分けはステイルメイト・反復などの自動判定です。

## マインスイーパー

`minesweeper` で中級を開始します。難易度を指定する場合は `minesweeper easy` のように入力してください。

| 難易度 | 盤面 | 地雷 |
| --- | --- | --- |
| `easy`（初級） | 6×6 | 6個 |
| `normal`（中級・既定） | 8×8 | 10個 |
| `hard`（上級） | 10×10 | 20個 |

**行 → マス** の順にボタンを押して開きます。旗モードでは、同じ操作で旗を立て外しできます。初手と周囲8マスは安全で、空白は自動で開きます。

開いた数字をもう一度押すと、隣接する旗の数が数字と一致した場合に残りのマスをまとめて開きます。旗が間違っていると地雷を踏むことがあるため注意してください。
全ての安全なマスを開くとクリアです。最終操作から10分で終了し、終了後は同じ難易度で再挑戦できます。

## 盤面と手番

盤面に対応する数字・文字のボタンを押します。置けない場所や相手の手番では操作できません。
オセロ・四目並べは1手3分、じゃんけん・ハイローの選択は60秒です。時間切れになる前に操作してください。

## 終了・再戦

途中でやめるときは `leave` を入力し、確認ボタンを押します。確認を開くだけでは終了しません。
終了カードの再戦ボタンは、元の募集者が使えます。

勝敗によるポイントは [報酬の目安](points.md) を確認してください。
