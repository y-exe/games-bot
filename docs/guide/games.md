# ゲーム

[目次](../README.md) · [ポイント](points.md)

## 始め方

チャットにコマンドを入力します。対戦ゲームは相手を募集し、「承認する」で参加します。`othello @相手` のように相手を指定することもできます。募集者は「キャンセル」で取り消せます。

オセロ・四目並べ・チェス・じゃんけんは「Botと対戦」でも遊べます。人間を指名したオセロ・チェスはBot戦に切り替えられません。マインスイーパーはひとり用、ハイローは人同士の対戦です。

## オセロ

- **開始**：`othello`。募集カードで6×6・8×8・10×10を選びます。先手・後手はランダムです。
- **操作**：相手の石を挟めるマスに置きます。盤面の数字・英字と同じボタンを押すと、挟んだ石が自分の色になります。候補が多いときは「次の候補」で切り替えます。
- **決着**：置けない手番は自動でパス。両者とも置けなくなると終了し、石の多い側が勝ち、同数なら引き分けです。1手3分で、投了・時間切れは負けになります。

## 四目並べ

- **開始**：`connectfour` / `cf`。7列×6段の盤面で、先手・後手はランダムです。
- **操作**：列のボタンを押すと、空いている一番下に石が落ちます。満杯の列は選べません。相手の並びを止めながら、自分の4個並びを狙います。
- **決着**：縦・横・斜めのどれかに先に4個並べた側が勝ちです。盤面が埋まると引き分け。1手3分で、投了・時間切れは負けになります。

## じゃんけん

- **開始**：`janken`。相手の参加後、グー・チョキ・パーを選びます。
- **操作**：ボタンで一度だけ選択します。手は両者が選ぶまで非公開で、自分の選択後は相手を待ちます。
- **決着**：両者の手が揃うと通常のじゃんけんで判定し、同じ手なら引き分けです。選択期限は60秒。途中終了・時間切れでは勝敗による報酬はありません。

## ハイロー

- **開始**：`highlow 100`。指名する場合は `highlow 100 @相手`。参加時に両者から同額のポイントを預かります。
- **操作**：表示されたカードを見て、次が大きいなら「HIGH」、小さいなら「LOW」を選びます。相手の選択は非公開で、同じ数字が出ると引き直します。
- **決着**：単独正解なら賭け金の合計を受け取り、両者正解なら返金、両者不正解なら没収です。選択期限は60秒。途中終了・時間切れは両者に返金します。

## チェス

- **開始**：`chess` / `チェス`。募集カードで持ち時間を選びます。5分・10分＋5秒・15分＋10秒・30分に対応し、既定は各10分＋着手ごとに5秒です。白黒はランダムです。
- **操作**：駒 → 移動先の順にボタンで選びます。青は選択中、緑は移動先、赤は駒取り・チェックです。候補はページで切り替え、ポーンの昇格先は4種類から選べます。キャスリング・アンパッサンにも対応します。
- **決着**：チェックメイトで勝利、ステイルメイトや駒不足などは引き分けです。3回反復・50手ルールは「引き分けを申告」で、予定手による申告もできます。5回反復・75手ルールは自動判定です。相手への引き分け提案もできます。

駒選択・昇格待ちも時計は進みます。時間切れ・投了は負けですが、相手に詰ませる手段がないと判定できる場合は引き分けです。複雑なデッドポジションの完全判定には未対応です。

## マインスイーパー

- **開始**：`minesweeper` / `マインスイーパー`。初級・中級・上級のボタンで難易度を選びます。`minesweeper easy` のように指定すると直接開始します。
- **操作**：行 → マスの順にボタンで開きます。数字は周囲の地雷数で、初手と周囲8マスは安全です。旗モードで旗を立て外しでき、数字と周囲の旗の数が一致すると「周囲を開く」が使えます。誤った旗には注意してください。
- **決着**：安全なマスをすべて開くとクリア、地雷を開くと失敗です。最終操作から10分で終了します。失敗・中断によるポイントの減少はありません。

| 難易度 | 盤面 | 地雷 |
| --- | --- | --- |
| `easy`（初級） | 6×6 | 6個 |
| `normal`（中級） | 8×8 | 10個 |
| `hard`（上級） | 10×10 | 20個 |

10行目の座標は数字の代わりに **A** と表示します。

## 終了・再戦

途中でやめるときは `leave` またはゲームの終了ボタンを押し、確認します。確認を開くだけでは終了しません。
終了カードの再戦ボタンは元の実行者が使えます。マインスイーパーは同じ難易度で再挑戦し、対戦ゲームは募集し直します。Botの再起動時は進行中のゲームを終了します。

報酬は [ポイント](points.md) を参照してください。
