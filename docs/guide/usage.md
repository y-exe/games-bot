# はじめに

[目次](../README.md)

## まず使ってみる

1. Botを使えるチャンネルで `/help` を開く。
2. カテゴリからコマンドを選び、チャットに入力する。
3. 対戦や確認は、返信カードのボタンで操作する。

```text
othello
login
text おはよう
tenki 東京
```

スラッシュコマンドは **`/help` と `/imakita`** です。それ以外は先頭の `/` を付けずに入力します。`オセロ`・`ログボ`・`天気` などの別名も使えます。
文字や添付が必要なコマンドは、引数なしで入力するとフォームが開きます。

## 管理者の準備

Botを使わせたいチャンネルで `setchannel` を入力します。同じ場所で再実行すると停止します。サーバー管理者権限が必要です。
現在のチャット入力は許可済みチャンネルだけを読み取ります。新規導入時の最初の登録や、停止後の再開には [セットアップのチャンネル登録](../operations/setup.md#最初の利用チャンネルを登録) を使ってください。
`/imakita` は未設定のチャンネルでも利用でき、結果は本人だけに表示されます。
`/help` もどのチャンネルでも使えます。許可済みなら公開、未設定なら本人だけに表示します。文字コマンドの `help` は許可済みチャンネル専用です。ヘルプのページ切替は実行した本人だけが操作できます。

スラッシュコマンドが見つからない場合は、許可済みチャンネルで `sync` を実行します。Bot所有者またはサーバー管理者が実行できます。

## ボタンが使えなくなったら

使い方・時計・要約などのボタンは一定時間で無効になります。コマンドを入力し直してください。
ゲームの手番や送金の確認には別の期限があるため、カード内の案内を確認してください。

## バグ報告

エラー画面・エラーログの **「バグを報告」** からフォームを開き、した操作と困ったことを入力します。操作名・発生時刻・エラーIDは自動入力されます。IDがない案内では省略されます。

エラーが出ない不具合は [報告フォーム](https://github.com/y-exe/games-bot/issues/new?template=bug-report.yml) を使ってください。GitHubへのログインが必要で、送信前に編集できます。
報告は公開されます。個人情報や非公開の会話は載せず、秘密情報に関わる問題は [専用の連絡先](../../SECURITY.md) へ送ってください。
