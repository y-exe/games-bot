## 会話を要約する

`/imakita` で直近の会話を3行にまとめます。範囲は **10分・30分・60分** から選べ、省略時は30分です。結果は本人だけに表示されます。

- 範囲ボタン：取得する時間の長さを切り替え。
- 「さらに詳しく」：同じ取得結果を時間帯別に表示。10分は5分刻み、30分は10分刻み、60分は15分刻み。
- 最新の会話を確認：コマンドを再実行。

同じチャンネル・範囲の取得結果は2分間共有し、同じ取得結果の要約を再利用します。再実行直後もキャッシュ中は同じ内容になります。
履歴は最大200件を取得し、範囲内を取り切れなかった場合はカードに表示します。Botの「メッセージ履歴を読む」権限が必要です。

## 天気・為替・時計など

| 入力例 | 内容 |
| --- | --- |
| `tenki 東京` | 3日分の天気。ボタンで都市を切替 |
| `rate 100 USD` | 外貨を日本円へ換算 |
| `time US` | 指定国の時計。省略時は日本 |
| `info @相手` | プロフィール・ロール・バッジ |
| `totusi おはよう` | 「突然の死」の文字飾り |
| `ping` | pongカードに応答速度・稼働時間・メモリを表示 |

天気は最大10分、為替は最大5分キャッシュします。都市・国・通貨の切替は返信カードのボタンから行えます。
会話要約・地名の推測にはDeepSeek APIを使います。キーが未設定の場合は [管理者の設定](../operations/setup.md) を確認してください。
