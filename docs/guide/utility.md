# 便利機能

[目次](../README.md)

## 会話を要約する

`/imakita` で直近の会話を3行にまとめます。範囲は **10分・30分・60分** から選べ、省略時は30分です。結果は本人だけに表示されます。

- 範囲ボタン：取得する時間の長さを切り替え。
- 「さらに詳しく」：同じ取得結果を時間帯別に表示。10分は5分刻み、30分は10分刻み、60分は15分刻み。
- 最新の会話を確認：コマンドを再実行。

同じチャンネル・範囲の取得結果は2分間共有し、同じ取得結果の要約を再利用します。再実行直後もキャッシュ中は同じ内容になります。
履歴は最大200件を取得し、範囲内を取り切れなかった場合はカードに表示します。Botの「メッセージ履歴を読む」権限が必要です。

## 天気・為替・時計など

| 入力例 | 内容 |
| --- | --- |
| `tenki 東京` | 3日分の天気。ボタンで都市を切替 |
| `rate 100 USD` | 外貨を日本円へ換算 |
| `time US` | 指定国の時計。省略時は日本 |
| `info @相手` | プロフィール・ロール・バッジ |
| `totusi おはよう` | 「突然の死」の文字飾り |
| `ping` | pongカードに応答速度・稼働時間・メモリを表示 |

## 天気

`tenki 東京` のように地名を指定します。天気・気温などの3日分の予報を表示し、カードの都市ボタンで表示先を切り替えられます。地名が曖昧な場合は都道府県も添えてください。天気は最大10分キャッシュします。

## 為替

`rate 100 USD` は100米ドルの円換算を表示します。金額と通貨を指定し、通貨ボタンでも切り替えられます。取得レートは最大5分キャッシュするため、決済時の金額とは異なる場合があります。

## 世界時計

`time` は日本、`time US` は指定国の時刻を表示します。カードの国ボタンで表示を切り替えられます。

## ユーザー情報

`info` は自分、`info @相手` は指定したユーザーの情報を表示します。


`info` はアカウント作成日・年齢、サーバー参加日、ロール、ブースト継続期間などをまとめて表示します。Bot内の利用履歴があればポイント・順位・連続ログインも表示します。参加順はサーバーの全メンバー情報が揃っている場合に表示し、画像は「アバターを見る」「バナーを見る」から開けます。


## 文字飾り・接続確認

`totusi おはよう` は指定した文字を「突然の死」の枠で囲みます。`ping` の返答は **pong** で、応答速度・稼働時間・メモリを確認できます。

会話要約・地名の推測にはDeepSeek APIを使います。キーの準備は [セットアップ](../operations/setup.md) を参照してください。
