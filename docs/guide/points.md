## 残高・受取・送金

| 入力例 | 内容 |
| --- | --- |
| `point` | 残高・ランキングを表示 |
| `login` | 1日1回のログインボーナスを受取 |
| `give @相手 100` | 相手へ送金。確認後に実行 |

`point` の「さらに表示（txt）」から、ポイントの多い順に上位1,000人の一覧をDiscord内のプレビューで読めます。名前は `表示名 (@ユーザー名)`、取得できない場合だけIDを表示します。長い一覧はファイルを分割し、本人だけに表示します。
表示名とユーザー名はDBに保存し、24時間を目安に更新します。更新に失敗した場合は、保存済みの名前を使います。

ログインは **日本時間0時** に切り替わります。通常報酬は連続日数と順位に応じて **30〜150pt**。連続5日目は **＋50pt**、10日目は **＋100pt** を加算します。10日目の次は1日目に戻り、「今後のログボ」で予測を確認できます。
送金には **15%の手数料（端数切り上げ）** がかかります。送金の確認期限は60秒です。確定前にカードで金額を確認してください。

徴収は毎日 **日本時間0時**。**前日にログボを受け取っていれば全額免除**です。24日の受取で25日0時、25日の受取で26日0時が免除されます。

| 所持ポイント | 免除されない場合の徴収 |
| --- | --- |
| 1万pt未満・借金中 | なし |
| 1万〜136万pt | 残高全体への税率が1%から3%へなめらかに増加 |
| 136万〜178万pt | 40,800pt＋136万ptを超えた部分の5% |
| 178万pt超 | 61,800pt＋178万ptを超えた部分の6% |

端数は切り捨てます。136万・178万ptを超えても、それまでの部分への税率は変わりません。`point` で翌日0時の徴収目安と免除状況を確認できます。

オセロの投了・時間切れでの勝利は別の基礎値で計算します。Bot戦の報酬は次のとおりです。

| ゲーム | 勝利 | 引分 | 敗北 |
| --- | --- | --- | --- |
| オセロ・6×6 | 80＋石差pt | +20pt | −20pt |
| オセロ・8×8 | 100＋石差×2pt | +25pt | −25pt |
| オセロ・10×10 | 140＋石差×3pt | +35pt | −30pt |

| じゃんけん | +25pt | +5pt | −10pt |

オセロの投了・時間切れは勝利の基礎値が人同士で90・120・150pt、Bot戦で60・80・100pt（6×6・8×8・10×10の順）になり、石差の加算は同じです。
ハイローは両者の賭け金を精算します。片方だけ正解すると合計額を受け取り、両者正解は返金、両者不正解は没収です。

チェスは **12半手（白黒6手ずつ）以上** 進んだ対戦でポイントが変動します。投了・時間切れでの勝利は人同士で+180pt、Bot戦で+120ptです。12半手未満は変動せず、Bot自身にポイントは付きません。

| マインスイーパー | クリア報酬 |
| --- | --- |
| 初級 | +60pt |
| 中級 | +120pt |
| 上級 | +220pt |

失敗・中断でポイントは減りません。

## Bet・ギャンブル

| 入力例 | 内容 |
| --- | --- |
| `bet 100` | 賭け金に対し−100%〜＋100%の増減 |
| `gamble` | 賭け金・倍率を抽選。確認して実行 |

賭け金の固定上限はありません。ギャンブルの変動は賭け金の−11倍〜＋9倍で、負けると残高がマイナスになることもあります。
賭け金はプラス残高なら所持額の約1/3〜全額、借金中なら借金額の5〜約10.89%（端数切り捨て・最低100pt）から抽選します。大きな借金では、最大の賭け金で10倍を引くと約98%を返済できます。残高0ptでは100ptです。
ギャンブルはプラス残高なら1日5回まで、0以下なら回数無制限です。ポイントはこのBot内のゲーム用です。
