# 画像・音声

[目次](../README.md)

## 文字を画像にする

| 入力例 | 見た目 |
| --- | --- |
| `text おはよう` | 黄色の縁取り |
| `text2 おはよう` | 青色 |
| `text3 おはよう` | 赤色・明朝体 |
| `text4 おはよう square` | 変形スタンプ |
| `text5 おはよう square` | 虹色スタンプ |
| `5000 5000兆円 欲しい` | 5000兆円欲しい風の画像 |

`text`〜`text3` はコンマで改行できます。末尾の `square` で正方形のスタンプにします。

## 画像を加工する

画像を添付して `watermark` または `gaming` を入力します。画像がない場合はフォームの案内に沿って指定してください。処理する画像はコマンドと一緒に添付すると確実です。

- `watermark`：端末などのテンプレートと画像を合成します。返信された画像を保存して使えます。
- `gaming`：添付した画像を七色に光るGIFへ変換します。返信されたファイルから動きを確認できます。

## 読み上げ・ボイチェン

`voice こんにちは` でVOICEVOXの読み上げとRVCの音声変換を行います。音声ファイルを添付して変換することもできます。利用できるサーバーは管理者の設定によります。
変換結果の案内はカード、音声は別の添付として表示し、Discord内のプレーヤーから再生できます。

添付音声は **45秒以内・10MB以下**、形式は `wav`・`mp3`・`flac`・`m4a`・`ogg` です。同時に処理できる音声は1件です。

音声環境の準備は [セットアップ](../operations/setup.md) を参照してください。
