# 画像・音声

[目次](../README.md)

## 文字を画像にする

| 入力例 | 見た目 |
| --- | --- |
| `text` / `text おはよう` | 種類を選んで生成 |
| `text1 おはよう` | 黄色の縁取り |
| `text2 おはよう` | 青色 |
| `text3 おはよう` | 赤色・明朝体 |
| `text4 おはよう square` | 変形スタンプ |
| `text5 おはよう square` | 虹色スタンプ |
| `textc おはよう` | カスタム文字の編集 |
| `5000 5000兆円 欲しい` | 5000兆円欲しい風の画像 |

`text1`〜`text3` はコンマで改行できます。末尾の `square` で正方形のスタンプにします。

`textc` の「編集画面を開く」から、本人限定のプレビューで調整できます。「画像を生成」を押すと、完成した画像をチャンネルへ公開します。

- **見た目**：16書体、塗り・グラデーション、背景・透明度。
- **配置**：斜体・回転、字間・行間、サイズ・余白。字間に固定の範囲はありません。
- **効果**：縁取り・影を合計24層まで追加し、編集・複製・並べ替え・削除。

「強制square化」は文字を正方形いっぱいに引き伸ばしてから縁取り・影を付けます。比率を維持して収めることもできます。

「保存」で自分の一覧に登録し、「共有カードを投稿」で他の人も追加できます。一覧から外しても、他の人の保存分は残ります。

「コードを表示」からコピーした設定は `textc スタイルコード` で復元できます。例：`tc1;font=mochiy;fill=#e674dc;layers=outline:#ffffff:8`。保存・共有されるのはデザインだけで、入力した文字は含みません。

## 画像を加工する

画像を添付して `watermark` または `gaming` を入力します。画像がない場合はフォームの案内に沿って指定してください。処理する画像はコマンドと一緒に添付すると確実です。

- `watermark`：端末などのテンプレートと画像を合成します。返信された画像を保存して使えます。
- `gaming`：添付した画像を七色に光るGIFへ変換します。返信されたファイルから動きを確認できます。

## 読み上げ・ボイチェン

`voice こんにちは` でVOICEVOXの読み上げとRVCの音声変換を行います。音声ファイルを添付して変換することもできます。利用できるサーバーは管理者の設定によります。
変換結果の案内はカード、音声は別の添付として表示し、Discord内のプレーヤーから再生できます。

添付音声は **45秒以内・10MB以下**、形式は `wav`・`mp3`・`flac`・`m4a`・`ogg` です。同時に処理できる音声は1件です。

音声環境の準備は [セットアップ](../operations/setup.md) を参照してください。
